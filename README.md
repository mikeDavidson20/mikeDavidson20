# Mythimon Legends

A browser-based monster-taming RPG inspired by classic creature battlers.

## Included content

- **40 custom species** generated with deterministic pixel-style sprites.
- **4-star evolution system** for every species (★ to ★★★★).
- **10 main world bosses** across unique regions.
- Capture, battle, team management, and manual evolution mechanics.

## Run locally

Because this is plain HTML/CSS/JS, any static server works.

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Gameplay loop

1. Select a region on the world panel.
2. Fight wild monsters or bosses.
3. Capture wild monsters and add them to your team.
4. Spend XP to evolve your active monster through 4 evolution stars.
5. Defeat all 10 bosses to complete the world.
