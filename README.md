# Mike's Screener

Mike's Screener is a Vercel-ready Next.js app that recommends buy/sell signals on stocks and options.

## Features
- Stock and options screener with buy/sell signals and confidence.
- Daily, weekly, and monthly price estimates.
- Per-symbol detail page with AI-style company synopsis and recent news bullets.
- Market-wide news page.

## Run locally
```bash
npm install
npm run dev
```

## Deploy to Vercel
1. Push this repository to GitHub.
2. Import it into Vercel.
3. Vercel will detect Next.js settings automatically.
